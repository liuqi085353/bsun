# ESUN-BENCH Website

Anonymous static project page for ESUN-BENCH.

## Deploy on GitHub Pages

Upload the contents of this folder to the root of a GitHub repository:

```text
index.html
.nojekyll
assets/demo.mp4
README.md
```

Do not upload the folder as a nested directory. The repository root must contain
`index.html` directly.

Then enable GitHub Pages:

1. Open the repository on GitHub.
2. Go to Settings -> Pages.
3. Set Source to "Deploy from a branch".
4. Select the branch you uploaded to, usually `main`.
5. Select `/ (root)` as the folder.
6. Save.

The page should be available after GitHub finishes the Pages deployment.
